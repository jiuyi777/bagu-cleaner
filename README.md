# 八股清理 v1.3.0

SillyTavern 扩展。检查角色卡和世界书里的 AI 八股，用 API 生成修改结果，你看过、改过再写入。

## 安装

在酒馆的 **扩展 → 安装扩展** 中粘贴仓库地址：

```text
https://github.com/jiuyi777/bagu-cleaner
```

安装后刷新酒馆。

手动安装：

把 `bagu-cleaner` 文件夹放进 `SillyTavern/public/scripts/extensions/third-party/`，刷新酒馆。

## 用法

扩展菜单（魔棒）→ **八股清理**

1. **检查范围**（选择会记住）
   - 角色卡：描述、性格、场景、开场白、**全部额外开场白**（1、2、3…各算一项）、对话示例、系统提示、历史后指令、内嵌世界书，逐个开关
   - 世界书：快捷选「全部 / 当前启用 / 角色绑定 / 清空」，也可以单独勾。勾了的世界书会读整本，**包括没启用的条目**
2. **我的八股词**：每行一个，查到就算必改。默认已经有「的弧度」。要用正则写 `re:` 开头
3. 点 **一键检查并改写** 一次跑完；也可以分开点 **① 检查**：每项显示命中。红色＝必改，橙色＝句式意象，绿色＝规则能直接删
4. **② 生成修改**，默认「检测到就交给 API 改写」：只把**含八股的整句**（带上前后句）交给 API，能删的删、删了不通顺的改写，长短不限；插件按原位置拼回，其他句子一字不动
   - 改完丢了 `{{char}}` 等宏、没改、或还含必改词的句子，单独重做一次；还不行就保留原句并提示，可以在结果框里自己改
   - API 可以选当前连接，或者酒馆「连接配置文件」里的任意一个
5. **修改结果直接是输入框**，随手改；改的时候实时提示还剩哪些必改项。也可以「对比原文」「重新生成」「放弃这项」
6. **③ 写入所选**：先备份再写；「撤销上次写入」一键还原，「下载上次备份」导出 JSON

## 其他模式

- 规则检测后交给 API 改句子：和默认模式一样按句修改
- 只用规则：不调 API
- 全部交给 API：没命中的段落也改

## 不会误伤的地方

- `{{char}}` 等宏、`<标签>`、代码块、链接不动；改完宏或标签数量变了会警告
- 本身就是禁用词清单的规则/提示词条目，标成「像规则/提示词」，默认不勾

## 高级

扩展设置 → 八股清理：规则分组开关、逐条开关、自定义正则（删除/替换/整句/标记）、API 提示词。

开场白改动只对新开的聊天生效。

## 1.3.0 整句修改

- 编辑单位从“命中的短语”改成“含八股的整句”，API 能看到整句和前后句，改出来更通顺。
- 去掉字数限制：可以删成空句，也可以改得比原来长。
- 只检查格式：宏不能丢、不能多出标签或代码；没改或还含必改词的句子单句重做。
- 旧版默认提示词自动更新；自定义提示词保留，发送时附加整句修改约束。

验证：`node tests/rewrite.test.mjs`（模拟 API 回包，检查实际插件处理路径）。
